# Marp practice - dogs slides

## How to run it

- **Install dependencies:**

```bash
npm install
```

- **Preview the slides in the browser:**

```bash
npm run marp-preview
```

- **Export to PDF:**

```bash
npm run marp-export
```

### Note

The scripts assume the following file names:

- The Markdown file is named dogs.md
- The custom theme is my-theme.css

If you rename these files, make sure to update the scripts in package.json.
